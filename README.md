# AI Sana Challenge Hub

MVP для трека «Образование» HackAlem AI. Представитель бизнеса описывает задачу своими словами,
получает уточняющие вопросы и редактируемую карточку. Прозрачный рейтинг 0–100 помогает улучшить
описание. После подтверждения задача появляется в каталоге; студенческие команды сами откликаются,
а бизнес вручную выбирает исполнителей.

## Архитектура

```text
браузер (Vite + React)
        │ /api
        ▼
FastAPI (backend/app/main.py) ── SQLite (backend/hub.db)
        ├─ tasks.py: черновик → вопросы → карточка → подтверждение → публикация
        ├─ ai.py → llm.py: строгий JSON, проверка дословных цитат, локальная заглушка
        ├─ rating.py: детерминированный рейтинг и подсказки
        ├─ catalog.py: каталог и рекомендации
        └─ proposals.py: отклики и ручное решение бизнеса
```

FastAPI отдаёт API и собранный `web/dist` с одного адреса. В режиме разработки Vite
проксирует `/api` на порт 8000. Данные для первого запуска синтетические, из `seed/*.json`.
ИИ не начисляет баллы и не назначает команды: он помогает сформулировать карточку. Значение,
предложенное ИИ, принимается только при наличии дословной цитаты из текста бизнеса. Некорректный
ответ повторно запрашивается; затем используется локальная заглушка.

## Рейтинг и каталог

Рейтинг считает `backend/app/rating.py` по подтверждённой человеком карточке. Формула из
[docs/03-rating.md](docs/03-rating.md): сумма семи показателей, максимум 100.

| Показатель | Формула | Макс. |
|---|---|---:|
| Контекст и потребность | контекст +6, потребность +6, число в контексте +4, число в потребности +4 | 20 |
| Данные и материалы | описание +8, источник +6, формат +3, объём или период числом +3 | 20 |
| Ожидаемый результат | описание +8, не менее 6 слов +4, число +3 | 15 |
| Критерии успеха | описание +5, числовая цель +7, метрика +3 | 15 |
| Ограничения | описание +5, числовая граница +3, категория ограничения +2 | 10 |
| Пользователи | названы +6, роль описана не менее чем 4 словами +4 | 10 |
| Связь с бизнесом | контакт в формате email, телефона, @ника или ссылки +6, формат взаимодействия +4 | 10 |

Дополнительные баллы показателя требуют содержательного основного поля. Пустые поля и заглушки
вроде «нет» и «не знаю» баллов не дают. В `breakdown` показано, за что начислен каждый балл;
`next_best` подсказывает, где возможен наибольший прирост. Текущая карточка получает
предпросмотр, а официальный рейтинг обновляется после подтверждения.

Уровни: `draft` 0–39, `working` 40–69, `ready` 70–89, `priority` 90–100.
Каталог показывает **все** опубликованные задачи, в том числе с низким рейтингом. Сортировка:
официальный балл по убыванию, при равенстве — более поздняя публикация выше. `draft` помечается
«требует уточнения», `priority` выделяется. Фильтры — отрасль и уровень. Командам рекомендуются
только опубликованные задачи от `working`, если слова их интересов, навыков или технологий
совпали с текстом задачи: у слов от пяти символов сравниваются первые пять, короткие слова —
целиком. Рекомендация не ограничивает каталог и не назначает исполнителя.

## Системные требования и запуск

- macOS, Linux или Windows (для Windows — ручные шаги ниже), Python **3.11–3.14**.
- Node.js **18+** и npm для веб-интерфейса. Если `web/package.json` отсутствует, `run.sh`
  поднимет API без сборки веба.
- Доступ к пакетным репозиториям при установке зависимостей. Ключ OpenAI для основного
  сценария не требуется.

Из корня чистого клона:

```bash
./run.sh
```

Скрипт создаёт `.venv`, устанавливает Python-зависимости, копирует `.env.example` в `.env`
при отсутствии файла, собирает веб при наличии `web/package.json`, **пересоздаёт**
`backend/hub.db` с синтетическими данными и запускает сервер на
`http://localhost:8000`. Порт можно задать через `PORT`. Проверьте
`http://localhost:8000/api/health`: ответ содержит `"ok": true`, `"db": "ok"` и режим
`"llm": "stub"` или `"llm": "llm"`.

Ручные шаги, macOS / Linux (`python3` — любой Python 3.11–3.14):

```bash
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
cp .env.example .env
cd backend
../.venv/bin/python -m app.db
../.venv/bin/uvicorn app.main:app --port 8000
```

Windows (PowerShell):

```powershell
python -m venv .venv
.venv\Scripts\pip install -r backend\requirements.txt
copy .env.example .env
cd backend
..\.venv\Scripts\python -m app.db
..\.venv\Scripts\uvicorn app.main:app --port 8000
```

Отдельно для веб-разработки, из корня проекта:

```bash
cd web
npm i
npm run dev
# npm run build создаёт web/dist для раздачи через FastAPI
```

Тесты из каталога `backend`:

```bash
../.venv/bin/python -m pytest
```

Тесты используют SQLite в памяти или временный файл и не меняют общую `backend/hub.db`.

## Переменные окружения

Образец — [.env.example](.env.example). `OPENAI_API_KEY` можно оставить пустым: тогда ИИ
работает в режиме `stub`, а весь обязательный сценарий доступен. `DEMO_MODE=1` принудительно
включает заглушку даже с ключом. `OPENAI_MODEL` задаёт модель семейства GPT-5 (по умолчанию
`gpt-5-mini`), `OPENAI_REASONING_EFFORT` — режим рассуждения,
`OPENAI_TIMEOUT` — таймаут запроса в секундах. `DB_PATH` задаёт файл SQLite; относительный
путь считается от `backend/`. `PORT` используется `run.sh`.

## Как проверить основной сценарий

Автоматическая проверка: `cd backend && ../.venv/bin/python -m pytest tests/test_scenario.py`.
Тест прогоняет API целиком без ключа OpenAI. Пошаговый сценарий для демонстрации за пять минут,
включая тексты для ввода, — [docs/04-demo.md](docs/04-demo.md).

1. Выбрать бизнес и создать слабый черновик. Получить рейтинг и минимум три вопроса.
2. Ответить на вопросы, дополнить карточку по подсказкам и увидеть рост рейтинга.
3. Подтвердить карточку и опубликовать задачу. Проверить её позицию в каталоге.
4. Выбрать команду и отправить отклик. Бизнес вручную принимает или отклоняет предложение.

Контракт запросов и ответов — [docs/02-api.md](docs/02-api.md). Промпты, схемы ИИ и обработка
ошибочного ответа доступны через `GET /api/ai/spec`.

## Сторонние компоненты и код до старта

Сторонние компоненты: **FastAPI**, **uvicorn**, **pydantic**, **openai SDK**,
**python-dotenv**, **pytest**, **httpx**, модель OpenAI семейства **GPT-5**,
**Vite** и **React**. SQLite входит в стандартную библиотеку Python.

Из подготовленного до начала соревновательной части (Положение, п. 5.4.4.2) в проекте осталась
только инфраструктура, не зависящая от кейса: структура репозитория, каркас FastAPI (чтение
`.env`, единый формат ошибок, транзакция на запрос, доменные ошибки), тестовая фикстура и
настройки pytest. Схема БД, контракт API, синтетические данные, рейтинг, ИИ-сценарий, каталог,
отклики и интерфейс написаны в ходе хакатона, после публикации кейса.
