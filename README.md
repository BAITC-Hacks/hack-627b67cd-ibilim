# AI Sana Challenge Hub

MVP по [ТЗ «Рейтинг качества бизнес задач и открытый выбор команд»](https://docs.google.com/document/d/1lFWekP2SirFarATKkWa5neHNL5DlhjZKkUacvGyZk8k/edit)
для трека «Образование» HackAlem AI. Представитель бизнеса описывает задачу своими словами,
получает уточняющие вопросы и редактируемую карточку. Прозрачный рейтинг 0–100 помогает улучшить
описание. После подтверждения задача появляется в каталоге; студенческие команды сами откликаются,
а бизнес вручную выбирает исполнителей.

## Сквозной сценарий по ТЗ

| Шаг ТЗ | Где в интерфейсе | Результат |
|---|---|---|
| 1–2. Черновик и уточнение | Бизнес → «Новая задача», затем `#/task/{id}` | Свободный ввод, проверка полноты, минимум три вопроса по недостающим сведениям |
| 3–4. Карточка и рейтинг | `#/task/{id}` | Десять редактируемых полей, расшифровка 0–100, подсказки, прогноз места, ручное подтверждение |
| 5. Публикация | «Опубликовать» → `#/catalog` | В общем каталоге задача сортируется по подтверждённому рейтингу |
| 6. Отклик команды | Команда → `#/catalog` → карточка | Любая команда отправляет идею, план, срок и ссылку на прототип; лимита откликов нет |
| 7. Решение бизнеса | Бизнес → «Мои задачи» → «Отклики» | Бизнес сравнивает предложения и вручную принимает или отклоняет каждое |
| 8. Результат этапа | Принятый отклик → «Подтвердить этап работы» | После фактического этапа бизнес начисляет команде 10 баллов; общий счёт виден в `#/stats` |

Для демо регистрация не нужна: роль и участник выбираются в шапке. Это переключатель демонстрационных
профилей, без проверки личности. Подробный маршрут с текстами для ввода —
[docs/04-demo.md](docs/04-demo.md).

## Что умеет

| Возможность | Как работает |
|---|---|
| Уточнение задачи ИИ | модель разбирает черновик и задаёт 3–5 вопросов по самым весомым показателям рейтинга |
| Карточка без выдумок | у каждого значения ИИ — цитата из текста бизнеса; нет цитаты или в значении число, email, ссылка, которых бизнес не писал, — значение отброшено и показано в `ai.warnings` |
| Помощник карточки | по слабым показателям предлагает до трёх формулировок с цитатой и ожидаемым приростом; бизнес применяет их по одной и подтверждает новую версию карточки; без живого ИИ помощник сообщает, что недоступен |
| Прозрачный рейтинг 0–100 | считает код, не модель: у каждого балла объяснение и подсказка «что добавить» |
| Защита от накрутки | вычеты за повтор текста в разных полях, набор ключевых слов, отписки, бессмыслицу (`penalties`) |
| Что даст улучшение | в `Task.rating` поле `next_best[].then` показывает балл, место и команды при доведении показателя до максимума; `audience.teams` — подходящие команды, `audience.recommended` включается от уровня `working` по текущему рейтингу |
| ИИ-студент | `POST /api/tasks/{id}/student-check`: модель в роли команды планирует первую неделю по карточке и отмечает допущения с вопросами бизнесу; проверка ничего не сохраняет |
| Персональные данные | ИИН с верной контрольной цифрой и номера карт по алгоритму Луна маскируются до записи в БД и до отправки в ИИ; упоминание ФИО, паспортов, диагнозов и т.п. — предупреждение до пометки об обезличивании (Закон РК «О персональных данных и их защите») |
| Каталог и отклики | все опубликованные задачи по рейтингу, фильтры по отрасли и уровню, рекомендации командам от уровня «рабочая»; отклики без лимита, решение принимает только бизнес |
| Баллы за прогресс команды | бизнес подтверждает выполненный этап принятого предложения; API начисляет команде 10 баллов, счёт показан в панели программы |
| Панель программы AI Sana | `GET /api/stats`: обезличенные агрегаты по задачам и отраслям, средний рост рейтинга от черновика, время ответа бизнеса, баллы и отклики команд |

## Архитектура

```text
браузер (Vite + React)
        │ /api
        ▼
FastAPI (backend/app/main.py) ── SQLite (backend/hub.db)
        ├─ tasks.py: черновик → вопросы → карточка → подтверждение → публикация
        ├─ ai.py → llm.py: строгий JSON, проверка цитат, помощник карточки, ИИ-студент, локальная заглушка
        ├─ privacy.py: маскирование ИИН и карт, предупреждения о персональных данных
        ├─ rating.py: детерминированный рейтинг, подсказки, вычеты за накрутку
        ├─ catalog.py: каталог, место в каталоге, рекомендации и аудитория задачи
        ├─ proposals.py: отклики, ручное решение бизнеса, подтверждённые этапы и баллы команд
        └─ stats.py: панель программы AI Sana
```

FastAPI отдаёт API и собранный `web/dist` с одного адреса. В режиме разработки Vite
проксирует `/api` на порт 8000. Данные для первого запуска синтетические, из `seed/*.json`.
ИИ не начисляет баллы и не назначает команды: он помогает сформулировать карточку. Значение,
предложенное ИИ, принимается только при наличии дословной цитаты из текста бизнеса. Некорректный
ответ повторно запрашивается; затем используется локальная заглушка.

Сид выполняет минимальный объём ТЗ §6: **5 черновиков, 5 опубликованных карточек, 5 профилей
команд и 5 откликов**. Бизнес-профилей тоже пять. Начальный рейтинг карточек пересчитывается
тем же кодом, что и рейтинг новых задач.

## Рейтинг и каталог

Рейтинг считает `backend/app/rating.py` по подтверждённой человеком карточке. Формула из
[docs/03-rating.md](docs/03-rating.md): сумма семи показателей, максимум 100.

| Показатель | Формула | Макс. |
|---|---|---:|
| Контекст и потребность | контекст +6, потребность +6, число в контексте +4, число в потребности +4 | 20 |
| Данные и материалы | описание +8, источник +6, формат +3, объём или период числом +3 | 20 |
| Ожидаемый результат | описание +8, не менее 6 слов +4, число +3 | 15 |
| Критерии успеха | описание +5, числовая цель +7, метрика +3 | 15 |
| Ограничения | описание +5, числовая граница +3, категория ограничения +2 | 10 |
| Пользователи | названы +6, роль описана не менее чем 4 словами +4 | 10 |
| Связь с бизнесом | контакт в формате email, телефона, @ника или ссылки +6, формат взаимодействия +4 | 10 |

Дополнительные баллы показателя требуют содержательного основного поля. Пустые поля и заглушки
вроде «нет» и «не знаю» баллов не дают. В `breakdown` показано, за что начислен каждый балл;
`next_best` подсказывает, где возможен наибольший прирост. Текущая карточка получает
предпросмотр, а официальный рейтинг обновляется после подтверждения.
`next_level.points_needed` показывает, сколько баллов осталось до следующего уровня;
на `priority` следующего уровня нет.
Отписки, бессмысленный текст, повтор одного описания в разных полях и набор ключевых слов
уменьшают рейтинг; каждый вычет и его причина показаны в `penalties`.

Уровни: `draft` 0–39, `working` 40–69, `ready` 70–89, `priority` 90–100.
Каталог показывает **все** опубликованные задачи, в том числе с низким рейтингом. Сортировка:
официальный балл по убыванию, при равенстве — более поздняя публикация выше. `draft` помечается
«требует уточнения», `priority` выделяется. Фильтр по теме в этом MVP — выбор отрасли задачи;
второй фильтр — уровень готовности. Командам рекомендуются
только опубликованные задачи от `working`, если слова их интересов, навыков или технологий
совпали с текстом задачи: у слов от пяти символов сравниваются первые пять, короткие слова —
целиком. Рекомендация не ограничивает каталог и не назначает исполнителя.
`position` показывает место опубликованной задачи по официальному баллу или прогноз места
черновика по текущему рейтингу; впереди считаются только задачи с баллом строго выше.

## Системные требования и запуск

- macOS, Linux или Windows (для Windows — ручные шаги ниже), Python **3.11–3.14**.
- Node.js **18+** и npm для веб-интерфейса.
- Доступ к пакетным репозиториям при установке зависимостей. Ключ OpenAI для основного
  сценария не требуется.

Из корня чистого клона:

```bash
./run.sh
```

Скрипт создаёт `.venv`, устанавливает Python-зависимости, копирует `.env.example` в `.env`
при отсутствии файла, собирает веб и **пересоздаёт**
`backend/hub.db` с синтетическими данными и запускает сервер на
`http://localhost:8000`. Порт можно задать через `PORT`. Проверьте
`http://localhost:8000/api/health`: ответ содержит `"ok": true`, `"db": "ok"` и режим
`"llm": "stub"` или `"llm": "llm"`.

Ручные шаги, macOS / Linux (`python3` — любой Python 3.11–3.14):

```bash
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
cp .env.example .env
cd web && npm ci && npm run build && cd ..
cd backend
../.venv/bin/python -m app.db
../.venv/bin/uvicorn app.main:app --port 8000
```

Windows (PowerShell):

```powershell
python -m venv .venv
.venv\Scripts\pip install -r backend\requirements.txt
Copy-Item .env.example .env
cd web
npm ci
npm run build
cd ..
cd backend
..\.venv\Scripts\python -m app.db
..\.venv\Scripts\uvicorn app.main:app --port 8000
```

Отдельно для веб-разработки, из корня проекта:

```bash
cd web
npm i
npm run dev
# npm run build создаёт web/dist для раздачи через FastAPI
```

Тесты из каталога `backend`:

```bash
../.venv/bin/python -m pytest
```

Тесты используют SQLite в памяти или временный файл и не меняют общую `backend/hub.db`.

## Переменные окружения

Образец — [.env.example](.env.example). `OPENAI_API_KEY` можно оставить пустым: тогда ИИ
работает в режиме `stub`, а весь обязательный сценарий доступен. `DEMO_MODE=1` принудительно
включает заглушку даже с ключом. `OPENAI_MODEL` задаёт модель семейства GPT-5 (по умолчанию
`gpt-5-mini`), `OPENAI_REASONING_EFFORT` — режим рассуждения,
`OPENAI_TIMEOUT` — таймаут запроса в секундах. `DB_PATH` задаёт файл SQLite; относительный
путь считается от `backend/`. `PORT` используется `run.sh`.

## Как проверить основной сценарий

Автоматическая проверка: `cd backend && ../.venv/bin/python -m pytest tests/test_scenario.py`.
Тест прогоняет API целиком без ключа OpenAI. Пошаговый сценарий для демонстрации за пять минут,
включая тексты для ввода, — [docs/04-demo.md](docs/04-demo.md).

1. На `http://localhost:8000/#/new` выбрать бизнес и ввести слабый черновик из
   [демо-сценария](docs/04-demo.md). Убедиться, что система задала не меньше трёх вопросов.
2. Ответить на вопросы. На `#/task/{id}` проверить десять полей карточки, рейтинг, его
   расшифровку, недостающие сведения и изменение баллов после правки. Кнопка «Помощник:
   дописать карточку» находится ниже полей; с ключом ИИ она предлагает формулировки с цитатами,
   без ключа честно сообщает, что помощник недоступен.
3. Подтвердить карточку и опубликовать задачу. Переключиться на команду, открыть `#/catalog`:
   задача должна стоять по подтверждённому баллу, фильтроваться по отрасли и уровню. Низкий
   рейтинг не должен скрывать опубликованную задачу или запрещать отклик.
4. Открыть задачу от имени команды и отправить идею, план, срок и ссылку. Переключиться обратно
   на бизнес: «Мои задачи» → «Отклики», сравнить предложения и вручную принять или отклонить.
   В «Мои отклики» команда увидит решение.
5. У принятого отклика после фактического результата вписать название этапа и нажать
   «Подтвердить этап». Проверить +10 баллов команды в `#/stats` после обновления показателей.

Дополнительные проверки ТЗ: повторно отредактировать опубликованную карточку — место в каталоге
должно измениться только после подтверждения; открыть `#/ai` — там видны промпты, форматы и
обработка ошибочного ответа; отключить `OPENAI_API_KEY` — основной сценарий работает на
локальной заглушке. Для работы без запущенного бэкенда можно открыть веб в режиме
`VITE_USE_MOCKS=true npm run dev` из каталога `web`.

Дополнительно: `POST /api/tasks/{id}/student-check` — проверка карточки ИИ-студентом;
`GET /api/stats` — панель программы; черновик с ИИН `900101300017` — в карточке `[ИИН скрыт]`.

Контракт запросов и ответов — [docs/02-api.md](docs/02-api.md). Промпты всех четырёх вызовов ИИ
(`analyze_draft`, `build_card`, `student_check`, `assist_card`), их схемы и обработка ошибочного ответа доступны
через `GET /api/ai/spec`. Модель по умолчанию — `gpt-5-mini`, задаётся в `OPENAI_MODEL`.

Публичная демо-ссылка: https://challenge-hub-production.up.railway.app. Она обновляется отдельным
деплоем; локальный коммит сам по себе не меняет публичный сайт. В контейнере Railway SQLite
хранится в `/tmp/hub.db`: при новом деплое база наполняется сидом заново, поэтому созданные
посетителями задачи и отклики между деплоями не сохраняются.

## Сторонние компоненты и код до старта

Сторонние компоненты: **FastAPI**, **uvicorn**, **pydantic**, **openai SDK**,
**python-dotenv**, **pytest**, **httpx**, модель OpenAI семейства **GPT-5**,
**Vite** и **React**. SQLite входит в стандартную библиотеку Python.

Из подготовленного до начала соревновательной части (Положение, п. 5.4.4.2) в проекте осталась
только инфраструктура, не зависящая от кейса: структура репозитория, каркас FastAPI (чтение
`.env`, единый формат ошибок, транзакция на запрос, доменные ошибки), тестовая фикстура и
настройки pytest. Схема БД, контракт API, синтетические данные, рейтинг, ИИ-сценарий, каталог,
отклики и интерфейс написаны в ходе хакатона, после публикации кейса.
