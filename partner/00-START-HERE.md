# iBilim — фронтенд. Начни отсюда

Хакатон HackAlem AI, трек «Образование». Нас двое: я делаю LLM и бэкенд, **ты — веб и деплой**.
В этой папке всё, что нужно тебе; остальное на моей стороне.

## Что за продукт, в трёх предложениях

Государство выдаёт школам типовую учебную программу, где каждая **цель обучения** имеет код
вида `7.2.1.4` (класс.раздел.подраздел.номер). Мы оцифровали этот граф и строим на нём цикл:
план на четверть → пакет урока для учителя → персональная домашка каждому ученику под его
пробелы → проверка (веб, фото, бумага) → карта пробелов → следующая домашка.

Отдельная фича: **индекс внешней помощи** — если ученик решил задачу методом, который класс
ещё не проходил, мы это видим, потому что знаем программу и дату.

## Твоя зона

```
web/            ← весь фронт твой
  Vite + React, без SSR, без UI-китов (свой CSS)
  сборка в web/dist — её раздаёт мой бэкенд, поэтому CORS нет и деплой один
```

Бэкенд поднимается на `:8000`, в dev настрой прокси `/api` → `http://localhost:8000`.

## Три правила, которые нельзя нарушать

1. **Контракт API заморожен.** Нужно новое поле — пишешь мне, я правлю `01-api.md` и бэк.
   Не изобретай поля на своей стороне: у меня они не появятся.
2. **Деплой в первый час, не в последний.** По регламенту проект, недоступный по публичной
   ссылке, отклоняют до финала. Поднимаем пустую оболочку сразу и дальше только обновляем.
3. **Телеметрия ввода на экране ученика обязательна** — `seconds`, `pastes`, `edits` по каждому
   полю ответа. Без неё половина детектора не работает, а это наша главная фича. Детали в `03-screens.md`.

## Стоп-код

За 20 минут до конца соревновательной части фронт замораживается: прогоняем демо-сценарий
целиком и пишем видео экрана на случай, если в зале умрёт Wi-Fi. Демо, которое не показали,
стоит ноль.

## Мелочи, которые экономят время

- Интерфейс на русском. Казахский в данных есть (`text_kk`), в UI не нужен.
- Всё должно работать при ширине экрана 390px: демо мы показываем с телефона.
- Генерация пакета урока идёт до 30 секунд — нужен честный лоадер с текстом, а не спиннер.
- Никаких аватарок, «красивых» дашбордов и анимаций. Смотрят на цикл, а не на градиенты.
