# Веб для AI Sana Challenge Hub — начни отсюда

**Идея поменялась.** Кейс трека «Образование» — платформа, где бизнес оформляет задачу для
студенческих команд. ТЗ: https://docs.google.com/document/d/1lFWekP2SirFarATKkWa5neHNL5DlhjZKkUacvGyZk8k
Контракт API — `partner/01-api.md`: заморожен, пока бэк не готов — мокай по примерам оттуда.

## Экраны

Все переходы должны работать в самом MVP — это обязательное демо (ТЗ §11). Вверху переключатель
роли: «Бизнес: …» (`GET /api/businesses`) / «Команда: …» (`GET /api/teams`). Регистрации нет.

**Бизнес**
1. **Новая задача**: поле черновика, отрасль (`meta.industries`), чипы-примеры
   (`meta.draft_examples`) → `POST /api/tasks`. Лоадер с текстом «ИИ разбирает черновик» (до ~20 с).
2. **Уточнение**: вопросы `task.questions`, поле ответа у каждого → `POST /api/tasks/{id}/answers`.
3. **Карточка + рейтинг**: 10 редактируемых полей (`meta.fields`), рядом панель рейтинга —
   большое число и уровень, 7 полос `breakdown` (points/max, explain, hint), блок «Что поднимет
   рейтинг» (`next_best` с «+gain»). Пока бизнес печатает — `POST /api/rating/preview` с debounce
   ~400 мс. «Сохранить» → `PUT /card`, «Подтвердить» → `POST /confirm`, «Опубликовать» →
   `POST /publish` (активна после подтверждения).
   - **Лента рейтинга** из `task.history` (12 → 38 → 81) — главный кадр демо.
   - Поле, заполненное ИИ, — значок «цитата» с `sources[поле]` при наведении.
   - `ai.mode === "stub"` — плашка «ИИ недоступен, работает локальная заглушка»; `ai.warnings` — списком.
4. **Мои задачи** (`GET /api/tasks?business_id=`) и **отклики по задаче**
   (`GET /api/tasks/{id}/proposals`): сравнение карточками, «Выбрать» / «Отклонить»
   (`POST /api/proposals/{id}/decision`), можно выбрать несколько или ни одного.

**Команда**
5. **Каталог** (`GET /api/catalog`): карточки по рейтингу, фильтры отрасль и уровень, бейдж
   «требует уточнения» (`needs_clarification`), выделение `highlight`. Блок «Рекомендуем вам»
   (`GET /api/teams/{id}/recommendations`) с тегами `match`.
6. **Отклик**: идея, план, срок, ссылка → `POST /api/tasks/{id}/proposals`; «Мои отклики» со
   статусами (`GET /api/teams/{id}/proposals`).

**Страница «Как работает ИИ»** (`GET /api/ai/spec`): промпты и схемы. ТЗ требует это показать.

## Правила

1. Контракт заморожен: нужно поле — пиши Арслану, он правит `01-api.md` и бэк.
2. **Код веба — только в этом репо (`web/`), и деплой — тоже из него**: разработка вне выданного
   репозитория — основание для дисквалификации (Положение, пп. 5.4.9, 5.9.2).
3. Уровни, подписи полей и показателей бери из `GET /api/meta`, не зашивай.
4. Мобильная адаптация не требуется (ТЗ §7), но интерфейс не должен разваливаться.
5. Бэк на `:8000`, в dev — прокси `/api` → `http://localhost:8000`; сборка в `web/dist`.
