# Скоуп на 5 часов, вдвоём

Команда — 2 человека, соревновательная часть 5 часов, обязателен публичный деплой.
Всё, что ниже отмечено «MVP-2», делается только если MVP-1 работает целиком.

## Вертикаль, которая должна работать по-настоящему

**7 класс, алгебра, один раздел (6 целей), русский язык интерфейса, казахский — как поле в данных.**

Одна работающая вертикаль весит на отборе больше, чем пять полуготовых: прототип 25 баллов,
реализация 15. Жирность показываем в README и на слайдах, а не в недоделанных экранах.

## MVP-1 — обязательный цикл

1. Граф целей загружен в БД, у целей есть `prerequisites`.
2. КТП: класс 7А, расписание, даты → список уроков с привязанными целями.
3. Пакет урока: КСП + объяснение + задания трёх уровней (генерация LLM, кеш).
4. Персональная домашка: 60% текущая цель, 40% просевшие цели ученика.
5. Сдача: **веб-форма** (ученик вводит ответы) и **фото** (учитель или ученик грузит снимок).
6. Проверка: эталон + дескрипторы, `sympy` на числах, порог уверенности → очередь учителю.
7. `mastery` обновляется, карта класса краснеет по проваленной цели.
8. Детектор: индекс внешней помощи с основаниями в кодах целей.
9. Экран учителя (план → урок → печать → сводка) и экран ученика (моя домашка → сдать → разбор).
10. Задеплоено и открывается по ссылке с телефона.

## MVP-2 — если останется время

- Печать бланков с QR (`window.print()` + qrcode-generator), распознавание QR с фото.
- Микро-опрос «объясни своё решение» при высоком индексе.
- Казахская версия текстов заданий.
- Генерация СОР со спецификацией.
- Пересчёт КТП при пропущенном уроке.

## Не входит вообще

Күнделік, парсинг учебников, ЕНТ, чат с учеником, мобильное приложение, регистрация школ,
роли завуча, оплата.

## Тайминг

| Час | A (LLM/бэк) | B (веб) |
|---|---|---|
| 0:00–0:20 | поднять скелет, БД, сид целей, `/api/health` | поднять Vite, layout, деплой пустой оболочки |
| 0:20–1:20 | планировщик КТП + `GET /api/classes/1/plan` | экран учителя: план на неделю, карточка урока |
| 1:20–2:20 | генерация пакета урока и заданий (schema + кеш) | экран урока: КСП, задания, кнопка «выдать домашку» |
| 2:20–3:20 | персональная домашка + `submissions` + sympy | экран ученика: домашка, форма ответов, загрузка фото |
| 3:20–4:10 | проверка по дескрипторам, mastery, сводка класса | карта класса, разбор ошибок, вид «Айдар / Дана» |
| 4:10–4:40 | детектор + основания | карточка индекса у учителя |
| 4:40–5:00 | **стоп-код.** README, прогон демо, запись экрана на случай падения сети | то же |

Жёсткое правило: в 4:40 код замораживается. Демо, которое не показали, стоит ноль.

## Деплой — в первый час, не в последний

Публичный URL поднимается на первом часу и дальше только обновляется. По регламенту
непубличный проект отклоняют до финала, и это самая глупая причина вылететь.
