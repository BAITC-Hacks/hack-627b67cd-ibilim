## Тексты

**Черновик:** Хотим понимать, какие поля скоро потребуют полива

**Ответы на вопросы:**
- Потребность — Сократить расход воды на 20% за сезон и не пересушивать поля
- Данные — Выгрузка с датчиков влажности почвы за 2 года, CSV, и карта полей
- Ожидаемый результат — Прототип дашборда с прогнозом полива на 7 дней по каждому полю
- Критерии успеха — Точность прогноза влажности не ниже 80% на исторических данных

**Дописать в карточку:**
- Название — Прогноз полива по полям
- Пользователи — Агрономы хозяйства, 5 человек, планируют полив каждое утро
- Ограничения — Срок 3 недели, только открытые библиотеки, данные не выносить за пределы хозяйства
- Контакт — agro@sever.kz
- Формат взаимодействия — Созвон раз в неделю, вопросы в Telegram, ответ в течение дня

**Отклик DataCats:** идея — Модель влажности по датчикам и погоде; план — 1) разбор данных
2) модель 3) дашборд; срок — 3 недели; ссылка — https://github.com/datacats/irrigation
