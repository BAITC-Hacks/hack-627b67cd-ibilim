## Правила работы

1. Отвечать по-русски.
2. Контракт API и схемы LLM зафиксированы: нужно новое поле — сначала правка `docs/02-api.md`
   (и копии `partner/01-api.md`), потом код.
3. Комментарии в коде — минимум, только в неочевидных местах, по-русски.
4. Не расширять скоуп сверх ТЗ: всё лишнее — после демо.
5. Код замораживается в 17:40, дальше README и прогон демо. Коммиты — каждый свою зону, каждый час (см. `AGENTS.md`).

## Запуск

```bash
cp .env.example .env                                   # OPENAI_API_KEY; без ключа — заглушка
python3.12 -m venv .venv && .venv/bin/pip install -r backend/requirements.txt
cd backend && ../.venv/bin/uvicorn app.main:app --reload --port 8000
../.venv/bin/python -m app.db                          # пересоздать БД и сид
```
