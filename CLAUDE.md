# CLAUDE.md — iBilim

**Прочитай `AGENTS.md` целиком перед первой задачей.** Это общий контекст проекта (он же для
Codex): что строим, стек, роли, правила, чего не делаем. Дальше — файл по своей области из
`docs/` (список в конце `AGENTS.md`).

Если задача про фронт — смотри `partner/`, это самодостаточная папка для второго разработчика.

## Правила работы

1. Отвечать по-русски.
2. Перед нетривиальной задачей — сверяться с `docs/`, а не изобретать заново: контракт API и
   схемы LLM уже зафиксированы. Нужно новое поле — сначала правка `docs/04-api.md`, потом код.
3. Комментарии в коде — минимум, только в неочевидных местах, по-русски.
4. Не расширять скоуп: всё, чего нет в `docs/02-scope-5h.md`, — после демо.
5. Хакатон: код замораживается за 20 минут до конца, дальше README и прогон демо.

## Запуск

```bash
cp .env.example .env                      # OPENAI_API_KEY, OPENAI_MODEL
cd backend && pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000  # http://localhost:8000/api/health
python -m app.db                           # пересоздать БД и сид
```
