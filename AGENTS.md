# AI Sana Challenge Hub — контекст проекта для агента

Корневой файл контекста, Codex читает его автоматически. Кейс трека «Образование» хакатона
HackAlem AI (23.09.2026). ТЗ: https://docs.google.com/document/d/1lFWekP2SirFarATKkWa5neHNL5DlhjZKkUacvGyZk8k
— выжимка и наши решения в `docs/01-case.md`.

## Что строим

MVP платформы, где представитель бизнеса превращает черновик своей задачи в полноценную карточку,
получает рейтинг готовности 0–100 и публикует задачу в общем каталоге; студенческие команды сами
откликаются, бизнес вручную выбирает, с кем работать. Сквозной сценарий:

```
черновик → ≥3 уточняющих вопроса (ИИ) → редактируемая карточка → рейтинг с расшифровкой →
подтверждение → публикация в каталоге по рейтингу → отклик команды → ручной выбор бизнеса
```

## Правила хакатона, которые нельзя нарушить

- Соревновательная часть 13:00–18:00; итоговая версия — состояние репо на 18:00 (Положение, п. 5.4.13).
- Эксперты сами разворачивают проект по README: не запустилось — снимают без права исправить (п. 5.4.16).
- Ключевой сценарий должен проверяться без наших ключей (п. 5.6.6): без `OPENAI_API_KEY` работает заглушка.
- Промежуточный результат каждый час — коммит и push (п. 5.4.8). **Коммиты делает только Арслан.**
- Сторонние компоненты и код, написанный до старта, раскрываются в README (пп. 5.4.4, 5.4.4.2).

## Критерии оценки (ТЗ §9, 100 баллов)

сквозной сценарий 20 · качество карточки 15 · **геймификация бизнеса 25** · каталог и отклики 15 ·
AI-функция 10 · техническое качество 10 · демо 5.

## Принципы — на них держатся баллы

1. **Рейтинг считает код, а не модель**: детерминированно, у каждого балла объяснение и подсказка
   (`rating.py`, формула — `docs/03-rating.md`).
2. **ИИ не добавляет фактов**: у каждого значения карточки — дословная цитата из текста
   пользователя, код проверяет, что цитата там есть; нет цитаты — значение отбрасывается.
3. Любой ответ LLM — JSON по строгой схеме; не сошлось — повтор, потом локальная заглушка (`ai.mode = stub`).
4. Карточку правит и подтверждает человек; позиция в каталоге — только по подтверждённой версии.
5. Команды никто не назначает: только отклики и ручное решение бизнеса.
6. Никаких персональных и чувствительных признаков участников.

## Стек

- backend: Python 3.11–3.12, FastAPI, SQLite, OpenAI SDK со Structured Outputs; LLM — только через `backend/app/llm.py`.
- web: Vite + React, fetch к `/api`, свой CSS. В проде FastAPI отдаёт и `/api`, и `web/dist` — одна ссылка.

## Кто что делает

Роль A ведут два агента в одной папке. Делим **по файлам**: чужие файлы не правим, даже «чуть-чуть».
Нужна правка в чужом файле — опиши, что нужно, Арслан передаст.

| Кто | Файлы | Задачи |
|---|---|---|
| **Claude** | `main.py`, `db.py`, `schema.sql`, `llm.py`, `errors.py`, `ai.py`, `tasks.py`, `tests/conftest.py`, `docs/` (кроме `03-rating.md`) | контракт, ИИ-функции, жизненный цикл задачи, все роуты |
| **Codex** | `rating.py`, `catalog.py`, `proposals.py`, `seed/*.json`, `tests/test_<модуль>.py`, `docs/03-rating.md`; в конце `README.md`, `Dockerfile` | рейтинг, каталог, отклики и выбор бизнеса, синтетические данные, README |
| **Напарник** | `web/` | все экраны сценария и деплой |

- Сигнатуры и докстринги в заготовках — контракт между агентами: `main.py` и `tasks.py` их
  вызывают. Тело пиши под них; сигнатуру меняет только Claude.
- Функции модулей получают `conn` и **не делают `commit`** — транзакцию закрывает роут в `main.py`.
  Ошибки — `errors.NotFound / Conflict / BadRequest`, в HTTP их переводит `main.py`.
- Тесты: `cd backend && ../.venv/bin/python -m pytest`; фикстура `conn` из `tests/conftest.py` —
  БД в памяти со схемой и сидом. Общую `ibilim.db` тесты не трогают.

## Команды

```bash
python3.12 -m venv .venv && .venv/bin/pip install -r backend/requirements.txt
cd backend && ../.venv/bin/uvicorn app.main:app --reload --port 8000   # http://localhost:8000/api/health
../.venv/bin/python -m app.db       # пересоздать БД и сид
../.venv/bin/python -m pytest       # тесты, БД в памяти
cd web && npm i && npm run dev      # прокси /api → :8000; npm run build → web/dist
```
