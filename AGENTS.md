# iBilim — контекст проекта для агента

Это корневой файл контекста. Codex читает его автоматически. Перед любой задачей прочитай
`docs/02-scope-5h.md` (что вообще делаем) и файл по своей области из списка внизу.

## Что строим

**iBilim — агент школьной программы Казахстана.** Замкнутый цикл вокруг одного ключа —
кода цели обучения из государственной типовой учебной программы (`7.2.1.4`):

```
граф целей → КТП (дата→цели) → пакет урока (КСП) → персональная домашка →
проверка (веб/фото) → карта пробелов (mastery) → следующая домашка и следующий урок
```

Плюс фича, которой нет ни у кого: **детектор «решение из будущего»** — метод в решении
принадлежит цели, которую класс ещё не проходил. Это не стилометрия, а сверка с графом.

Хакатон HackAlem AI, 23.09.2026, трек «Образование». Команда — 2 человека.
Проект обязан быть развёрнут по публичной ссылке, иначе его отклоняют до финала.

## Роли (двое)

| | Кто | Область | Файлы |
|---|---|---|---|
| **A** | Арслан | LLM + бэкенд: граф целей, генерация, проверка, детектор, API | `backend/` |
| **B** | напарник | Веб: экраны учителя и ученика, печать бланков, деплой | `web/` |

Контракт между ними — `docs/04-api.md`. Он заморожен: **менять эндпоинты и поля можно
только правкой этого файла**, потому что второй человек пишет против него вслепую.

## Стек (решено, не обсуждается во время хакатона)

- **backend**: Python 3.11, FastAPI, SQLite (файл `ibilim.db`), OpenAI SDK со Structured Outputs.
- **web**: Vite + React (без SSR), fetch к `/api`. Никаких UI-фреймворков, свой CSS.
- **деплой**: один сервис — FastAPI отдаёт `/api/*` и статику из `web/dist`. Без CORS, одна ссылка.
- **LLM**: `OPENAI_MODEL` из `.env`. Весь вызов LLM идёт через `backend/app/llm.py`,
  нигде больше OpenAI не импортируется.

## Правила кода

1. **Никакого свободного текста между слоями.** Любой ответ LLM — JSON по схеме из
   `docs/05-llm.md` (Structured Outputs, `strict: true`). Если схема не сошлась — ретрай, не «починка регуляркой».
2. **Задание генерируется вместе с эталоном и дескрипторами.** Без эталона задание не существует —
   проверять будет нечем.
3. **Числовые ответы проверяет `sympy`, а не модель.** LLM разбирает метод и шаги, арифметику
   считает код.
4. Всё, что связано с ученической успеваемостью, пишется через `mastery` — единственный источник
   правды о пробелах.
5. Данные детей: ни email, ни телефон ученика. Имя + класс. В демо-сиде реальных людей нет.
6. Коммиты — почасовые, в выданное репо (требование регламента п. 8). Каждая рабочая
   вертикаль коммитится сразу, а не в конце.
7. Код, написанный до старта (парсеры, сид, скелет), раскрывается в README — это разрешено
   регламентом (п. 6.4), но должно быть явно названо.

## Чего НЕ делаем (решено заранее, не возвращаться)

- **Не парсим учебники.** Права у издательств (Атамұра, Мектеп, Алматыкітап), публичное демо с их
  контентом нас топит. Только оглавление как метаданные: `§14, стр. 87 → [коды целей]`.
- **Не интегрируем Күнделік.** OAuth2 с ручной выдачей client_id — за день не получить. Свой журнал.
- **Не делаем нативное приложение.** PWA: устанавливается с экрана, камера работает, App Store не участвует.
- **Не делаем ЕНТ-тренажёр** (там iTest с 16 тыс. вопросов) и **не делаем чат-репетитора**
  (Bilim AI, WONK) — мы про сторону учителя и про ежедневный цикл.
- **Не используем американские стандарты**: Common Core не открытая лицензия, CK-12/Khan — NC
  (запрет коммерческого использования).
- **Не делаем стилометрический ИИ-детектор**: 61,3% ложных срабатываний у неносителей языка.

## Термины (чтобы не путаться)

- **Цель обучения** — единица программы с кодом `класс.раздел.подраздел.номер`, например `7.2.1.4`.
- **ДСП / КТП** — долгосрочный план: распределение целей по четвертям; даёт государство.
- **ССП** — среднесрочный план по разделу. **КСП** — краткосрочный план урока, обязателен на каждый урок.
- **СОР / СОЧ** — суммативное оценивание за раздел / за четверть, с критериями и дескрипторами.
- **Дескриптор** — строка критерия оценивания: «применяет формулу разности квадратов — 1 балл».
- **mastery** — освоенность цели конкретным учеником, 0…1.
